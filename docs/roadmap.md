## Изменения относительно исходного плана

1. **ML-трек.** В исходном плане бэкенд только загружал готовые веса, а обучение и сравнение моделей из задач 3–4 (ResNet / EfficientNet / ViT, маски OpenCV → U-Net, бустинг против LSTM) не было запланировано.
2. **pr-074.** Модель Гойданича описывает инкубационный период милдью, а не оидиума. Для оидиума добавлен индекс Gubler–Thomas.
3. **pr-073.** Условие «побеги ≥ 10 см» не выводится из метеоданных, поэтому длина побегов берётся по фенофазе или сумме активных температур.
4. **pr-033.** Добавлен импорт границ виноградников из OpenStreetMap — источник данных из задачи 2.
5. **pr-043, pr-047, pr-065, pr-075, pr-076.** Вместо готовых весов подключаются модели и методы, выбранные в ML-треке.
6. **Данные.** В PlantVillage у винограда 4 класса, милдью и оидиума среди них нет, хотя именно их прогнозирует метеомодуль. Отсюда ml/pr-003 и ml/pr-004.

## Стратегия тестирования

| Уровень | Инструменты | Что проверяется | Материал для отчёта |
|---|---|---|---|
| Модульные | pytest, pytest-mock | бизнес-логика, агромодели, схемы | покрытие (цель > 85 %), таблицы результатов |
| Интеграционные | pytest-asyncio, httpx, Testcontainers | API, запросы PostGIS, задачи Celery | логи запросов и ответов, схема БД |
| Оценка моделей | scikit-learn, torchmetrics | классификаторы, U-Net, бустинг и LSTM | матрицы ошибок, ROC-AUC, precision / recall / F1, IoU / Dice |
| Нагрузочные | Locust | производительность при 100+ RPS | графики RPS, задержки p95/p99, ошибки |

## Риски

| Риск | Решение |
|---|---|
| Облачность на снимках Sentinel-2 | фильтр облачности (< 10 %), интерполяция по предыдущим датам, NDRE как дополнительный индекс |
| Плохое качество полевых фото | проверка резкости перед отправкой, аугментации при обучении |
| Модели, обученные на лабораторных фото, хуже работают на полевых | полевой тестовый набор (ml/pr-004), отдельная оценка на нём |
| В открытых датасетах нет милдью и оидиума | дополнительные датасеты (ml/pr-003), собственные фото (ml/pr-004) |
| Долгие ГИС- и ML-вычисления | фоновые задачи Celery, кэширование слоёв, ONNX Runtime |
| Нет интернета на виноградниках | PWA с квантованной ONNX-моделью прямо в браузере |
