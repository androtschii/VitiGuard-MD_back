# Открытые данные для модели лозы

Реестр наборов для модели «ствол + гроздь» (ml/pr-023). Набор попадает в обучение только после проверки лицензии и разметки. Новые находки добавляются сюда со статусом «найден», и в обучение их переводят по одному, сравнивая версии модели на одной тестовой выборке.

| Набор | Что размечено | Лицензия | Статус |
|---|---|---|---|
| [INESC TEC, Grape bunch and vine trunk dataset](https://doi.org/10.5281/zenodo.5114141) (Aguiar, Magalhães) | стволы, грозди двух размеров; рамки, Pascal VOC; 2476 исходных кадров без искусственных копий и тепловизора | CC BY 4.0 | в обучении |
| Тот же архив INESC, вторая камера (кадры `rotated_left`) | только стволы: 370 кадров 640×480, 1144 рамки | CC BY 4.0 | в обучении с 3 ноября 2026: 320 кадров в обучение, 50 в проверку, в тест не идут |
| [Embrapa WGISD](https://github.com/thsant/wgisd) (Santos и др.) | грозди пяти винных сортов; рамки и маски | CC BY-NC 4.0, не для коммерции | в обучении |
| [VineSet, INESC TEC](https://doi.org/10.5281/zenodo.5362354) (Santos, Aguiar, Santos) | стволы, 9481 кадр с искусственными копиями, Pascal VOC | CC BY 4.0 | не нужен: 917 исходных кадров побайтно совпадают с кадрами архива INESC выше, рамки те же |
| [Roboflow Universe, vineyard trunk & foliage](https://universe.roboflow.com/gokila/vineyard-trunk-foliage-detection) | стволы и листва | по описанию CC BY 4.0, не проверена | найден: для скачивания нужен аккаунт Roboflow |
| [HUMAIN-Lab, vine-trunk](https://github.com/humain-lab/vine-trunk) (Badeka и др.) | стволы; 629 исходных снимков 416×416 и 1887 искусственных копий, рамки LabelImg | не указана | не подходит: в репозитории нет лицензии |
| [Mendeley Data, Vineyard dataset for pruning](https://doi.org/10.17632/n8cs4ns97p.2) (Pacioni и др.) | стволы, побеги до и после обрезки; 536 кадров, контуры VIA (полигоны) | CC BY 4.0 | найден: конвертер полигонов VIA в рамки готов; архив скачивается вручную, формат нужно сверить с настоящими данными |
| Roboflow Universe, Vinyard Trunk Detection (Agricultural Automation and Robotics Lab) | стволы, столбы; 164 кадра, рамки | по описанию CC BY 4.0, не проверена | найден: ссылка на проект не записана, для скачивания нужен аккаунт Roboflow |
| [GrapeMOTS](https://doi.org/10.1016/j.compag.2024.108845) (UAV видео) | грозди, стволы и столбы в отдельных рядах | CC BY 4.0 | не подходит: ракурс БПЛА сверху, стволы видны под острым углом |
| [Riseholme UAV Vineyard](https://doi.org/10.5281/zenodo.15211733) (Polvara и др.) | стволы, столбы, ряды, крона; маски COCO | CC BY 4.0 | не подходит: съёмка БПЛА сверху, не совпадает с ракурсом камеры робота на шпалере |
| [Semantic Segmentation Vineyard Rows](https://doi.org/10.5281/zenodo.4601472) (Radcliffe и др.) | ряды виноградника, междурядья; снимки с наземного робота | CC BY 4.0 | найден: сегментация рядов для навигации, без отдельных рамок стволов |

Правила:

- Берутся только исходные кадры: искусственные копии из архивов (повороты, отражения, шум) отбрасываются, аугментацию делает обучение.
- Кадры из видео делятся на выборки блоками соседних кадров, а не случайно: соседние кадры почти одинаковы.
- Тестовая выборка после первого обучения не меняется: только так версии модели сравнимы между собой.

# Полевые данные для модели болезней листа

Реестр наборов для дообучения на полевых снимках (ml/fine-01…06). Лицензии сверены по описанию набора в API Mendeley Data.

| Набор | Что там | Лицензия | Статус |
|---|---|---|---|
| [Tardif et al., Flavescence dorée и похожие болезни](https://doi.org/10.17632/3dr9r3w3jn.2) | 1 483 полевых снимка пяти сортов: золотистое пожелтение, эска, похожие стрессы; разметка по снимку, у 744 — рамки листьев | CC BY 4.0 | ml/fine-01: снимки куста для фильтра; ml/fine-04: класс «пожелтение» |
| [GVLiD](https://doi.org/10.17632/wkymf8bhcg.5) | 3 477 полевых фото листьев 1080×1080: здоровый, чёрная гниль, эска, пятнистость | CC BY 4.0 | найден: ml/fine-02 |
| [ESCA-dataset](https://doi.org/10.17632/89cnxc58kj.1) | листья с эской и здоровые | CC BY 4.0 | найден: ml/fine-05 |
| [Merlot downy mildew](https://doi.org/10.17632/yxf2yv5ymt.1) (Abdelghafour и др.) | 99 снимков с трактора, попиксельная разметка милдью | CC BY-NC-ND 4.0 | только для проверки: без переделок и не для коммерции |
| [Imagenette](https://github.com/fastai/imagenette) (fast.ai) | 10 классов ImageNet, 160 px | Apache 2.0 | ml/fine-01: «не виноград» для фильтра |
